# 3D UrbanPrint (demo)

3D printerda yasalgan buyumlar (svetilnik, brelok, o'yinchoq) sotadigan sayt uchun ko'rish demosi.

Demo: https://cubercaat.github.io/urbanprint-demo/

Bu statik demo: mahsulotlar namunaviy, to'lov, kabinet va admin panel ishlamaydi.
To'liq sayt (Node.js server, admin panel, Click va Payme) alohida shaxsiy repoda.

Ichida: three.js (MIT) bilan haqiqiy 3D printer sahnasi. Skroll qilganda buyum qatlam-qatlam chop etiladi va pastga tushadi.
